07 · ЗапускFin-Audit RL Gym

Одна
команда

Тесты, проверка данных и эталона, базовые политики, парные проверки и разбор сбоев запускаются одной командой. Без сети, платных API и GPU.

# локально, Python 3.11, зависимостей нет
$ python -m auditenv check

# в контейнере, без сети
$ docker build -t fin-audit-rl .
$ docker run --rm --network none fin-audit-rl

# 10 train + 10 dev эпизодов и траектории
$ python -m auditenv export

# показ эпизода со скриптовой политикой
$ python -m auditenv demo
auditenv/generator.pyистория → проводки → ошибки → отрисовка
auditenv/env.pyreset / step, 100 шагов, 60 секунд
auditenv/matcher.pyнормализация, допуски, паросочетание, награда
auditenv/reference.pyнезависимая сверка по открытым записям
auditenv/server.pyизолированный процесс оценщика
auditenv/policies.pyчетыре адаптера базовых политик
tests/test_all.py27 тестов среды, matcher и награды
episodes/ · trajectories/открытые эпизоды и траектории

Честные ограничения

Упрощённая модельТолько дебиторская задолженность, один период, книги в базовой валюте.
Не реальный аудитВысокая награда не доказывает пригодность для реального аудита.
Открытый генераторЗакрытая проверка обязана использовать секретные seed и соль, иначе seed можно перебрать.
Без обучения весовМодель не обучалась, улучшение модели не заявляется.
