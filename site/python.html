Шпаргалка по среде

  
Агент получает описание компании, делает действия и в конце отправляет выводы. Каждое действие стоит 1 шаг, всего 100 шагов.

  

    
Начатьobs, info = env.reset(seed=42)
Новая компания. В obs["manifest"] — период, валюты, часовой пояс и число записей.

    
Читать таблицу{"name": "list_records", "args": {"table": "invoices", "limit": 50}}
Таблицы: ledger, invoices, payments, fx. Следующая страница — через cursor.

    
Одна запись{"name": "get_record", "args": {"table": "payments", "id": "PAY-…"}}
Или get_document по doc_id — полный счёт или платёж.

    
Посчитать{"name": "calculator", "args": {"expression": "1250.50 * 0.8015"}}
Точная десятичная арифметика без ошибок округления.

    
Отправить{"name": "submit", "args": {"findings": {"episode_id": …, "findings": [...]}}}
Вывод: type, affected_ids, claimed_amount_minor, currency, evidence_ids, explanation.

    
Ответ средыobs, reward, terminated, truncated, info = env.step(action)
Награда от −1 до +1 приходит после отправки: 2·F1 − 1 − 0,002·шаги.

  

  

    
duplicate_invoiceОдин и тот же счёт выставлен дважды

    
missing_or_partial_allocationОплата не разнесена или разнесена не полностью

    
fx_conversion_errorНеверный курс при пересчёте валюты

    
period_cutoff_errorДокумент проведён не в своём периоде

  





  

    
Запустить у себя

    
Нужен только Python 3.11 или новее — сторонних библиотек нет.

    
# скачать и проверить всё одной командой
$ git clone https://github.com/aiguzhin/in-audit-rl-gym
$ cd in-audit-rl-gym
$ python -m auditenv check

# примеры с этой страницы
$ python -m examples.02_find_duplicates

# 10 train + 10 dev эпизодов и траектории
$ python -m auditenv export

# в контейнере, без сети
$ docker build -t finspector . && docker run --rm --network none finspector
